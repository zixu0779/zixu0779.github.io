## 本地运行

本次本地验证使用 Node.js 24；依赖由 pnpm 和 `pnpm-lock.yaml` 管理。更换运行时版本后须重新验证构建，不默认所有旧版本都支持环境代理选项。

```sh
pnpm install --frozen-lockfile
# 安装后确认主题补丁已执行；重复执行安全
node lib/theme-patches.js

# 只生成静态文件，不部署、不上传搜索索引
NODE_USE_ENV_PROXY=1 node_modules/.bin/hexo generate

# 默认 http://localhost:4000/
npm run server
```

依赖安装通过 `package.json` 的 `install` 脚本直接执行 `node lib/theme-patches.js`；`install.sh` 仅保留为手动执行入口。补丁按完整语句调整随机文章、最新评论数量和其他主题行为，先检查全部匹配，再写入主题文件。安装时不要禁用生命周期脚本；若已禁用，须手动执行上述 Node.js 命令。

当前补丁适配 ShokaX 0.4.17，不保证未来版本直接兼容。关键模板替换和评论产物会检查匹配结果，发现不兼容时停止生成。升级后应适配报错位置并运行相关测试，再做电脑和手机端预览；匹配检查不能代替交互验证。

`NODE_USE_ENV_PROXY=1` 用于让支持此选项的 Node.js 版本使用环境代理；没有设置代理时不需要另外填入地址。构建可能获取远程图片元数据，网络异常须区分超时与真实 404。

当前 `build.sh` 只有 `hexo generate`，`npm run build` 调用它。`npm run deploy` 才执行发布。`npm run clean` 会同时删除 Hexo 缓存和 `.deploy_git`，不要把它当作每次预览的必要步骤。端口被占用时先识别已有服务，避免误停其他任务。

### 首次安装与原生依赖

2026 年 10 月 18 日在 macOS、Node.js 24、pnpm 12.11.2 下，用独立缓存和临时副本完成重装验证。普通安装命令会因未授权的依赖脚本报 `ERR_PNPM_IGNORED_BUILDS`。本次允许 `esbuild`、`hexo-util` 和 `deasync` 执行构建，禁用当前本地生成不需要的 Puppeteer 安装脚本：

```sh
pnpm install --frozen-lockfile \
  --allow-build esbuild --allow-build hexo-util \
  --allow-build deasync --allow-build '!puppeteer'
```

pnpm 12 会将这些选择写入 `pnpm-workspace.yaml` 的 `allowBuilds`。这是依赖脚本授权，不要直接允许所有依赖执行脚本；上面的设置目前只在验证副本中使用，尚未加入本项目配置。

在本次 Node.js 24 环境中，`deasync` 需要本机编译。若提示 `node-gyp: command not found`，先确认已安装 Python 和 macOS Command Line Tools，再使用临时工具重建：

```sh
npm exec --yes --package=node-gyp -- pnpm rebuild deasync
pnpm install --frozen-lockfile
```

其他系统需要各自的原生编译工具，尚未验证。上述问题处理后，本次安装、页面生成和 8 项相关回归检查通过；7 个主题补丁文件与项目一致，重复执行补丁不改变内容。这验证的是 ShokaX 0.4.17 的重装恢复，不代表兼容未来主题版本。

## 写作与文章整理

- 新文章先讨论主题、切入点与事实范围，再写草稿。以作者实际动机、观察、排查过程、结果和未解决问题组织内容，不虚构经历。
- 标题应突出主题，不把正文细节全部塞进标题。知识整理可用“笔记”，实际操作和阶段经历可用“记录”；题解、工具介绍及明确知识主题优先直接命名，避免机械添加后缀。
- 分类表达内容归属，标签表达具体技术、工具或主题。私人近况与琐碎事项归入生活记录的日常琐记；目前没有实现答题解锁，不能把分类折叠当成隐私保护。
- 重命名、分类整理、链接替换和图片显示优化不算正文更新：保留原有 `date`、`updated`，涉及迁移工具时也保留文件修改时间。
- 文件名和目录调整可能改变 URL。修改前检查站内硬编码链接、图片相对路径、精选配置、搜索数据和 Waline 评论路径；不能只修改标题后就忽略这些依赖。
- flag、下划线、波浪号、花括号及命令中的特殊字符按语义使用行内代码或代码块。检查生成页面中的实际文本，不靠添加转义字符猜测渲染结果。

### 过期提醒

沿用 ShokaX 的 `outime` 功能：启用后，**仅当最后更新年份早于当前年份**时显示。`days` 保留兼容但不再作为判断阈值。提示位于正文开头，使用“这是一篇发布于 XXXX年X月X日的文章，最后一次更新在 N 天前，…”的形式。逻辑和中文模板由 `lib/theme-patches.js` 维护，不再另外实现一套提醒。

## 图片、封面和头像

正文继续使用普通 Markdown：

```md
![准确的图片说明](原图链接)
```

每篇新文章必须逐图查看内容并精调展示宽度，不能只检查首图。简单代码、终端截图中的文字尽量接近正文字号；复杂界面留足阅读空间；细条、长图、小图分别判断，不能机械套用同一上限。

- **原始尺寸与显示尺寸分开**：`image-dimensions.json` 记录真实原图宽高；`image_display.yml` 控制显示宽度，高度按比例计算。不能篡改原图比例达到缩放效果。
- **生成时预留空间**：延迟加载前后占位应稳定，不能等图片出现再调整正文布局。窄屏不横向溢出，不拉伸、不裁剪正文图。
- **保留原图**：Cloudinary 静态图片展示使用 `f_auto,q_auto` 和适当尺寸派生图；点击放大仍查看原图。自动格式可能返回 AVIF、WebP 或其他格式，不强制全部改成 WebP，不把后缀改名当作转换。
- **首屏与后续图片分开加载**：顶部大图第一张立即、高优先级加载，只预加载一次；轮播后续图延后加载，就绪后再切换。文章列表、分类封面和正文采用各自适合的尺寸和加载策略。
- **GIF 和外部图床**：不能丢失动画；没有可靠尺寸或可靠来源时保留原链接并报告。超时重试后再判断，404 没有备份时不拿无关图替换。
- **Cloudinary 目录**：正文图片放 `Typora/`，新增文章配图按对应文章日期归档；封面放 `Covers/`；首页画廊使用 `Gallery/`；壁纸资源放 `Wallpapers/`；站点图标与作者头像放 `sycamore.top/`。固定文件夹模式下移动会影响地址，先复制验证内容与可访问性，再更新全部引用和尺寸索引；删除旧资源另行确认。
- **精选配置**：`category_covers` 同时定义首页精选分类及其封面，当前保留软件开发、赛博朋克 2077、生活记录、网络安全四项。不要为每个普通分类补封面条目，否则会增加精选卡片。文章 front matter 中的封面另有用途，不能随精选条目一起删除；清理资源前检查全站引用。
- **头像**：银龙粉底用于浅色模式，蓝底用于深色模式，博客用 512 WebP，Waline 使用粉底 128 WebP，original 原图保留。精确指定底色时需验证像素，不能仅依据生成描述宣称颜色准确。友链头像沿用对方链接，不替别人强制换图。

详细验收要求见 [AGENTS.md 的配图流程](../AGENTS.md)。

## 界面与交互约定

### 分类和归档

- 分类入口统一指向 `/categories/` 下对应锚点；进入具体子分类时，自动展开并滚动到正确位置。
- 父分类和子分类按各自最新文章的**发布时间**降序排列；不要混同文章修改时间。
- 分类文章默认折叠，展开每页 5 篇，切换分组收起其他分组；不足一页不显示分页。
- 分类与归档共用 `archive_row`，分类与首页共用 `site_pagination`。保留一致的圆点、时间线、文字与分页行为，不另外拼一套近似组件。
- 长标题在日期右侧的剩余宽度内换行，续行与标题首行对齐，标题行高为 1.5；日期不被挤压，整段标题不跳到日期下一行。
- 分类分页只切换本分组页码，不能被普通锚点监听器拦截或重置为第一页。隐藏页码栏不占空间，固定左右箭头位置，展开与分页高度动画不得重复触发造成停顿。
- 归档在单页按年月列出全部文章，不恢复年月子归档页。

### 通用布局

- 保留顶部三层标题、主题图标与深浅色机制。改动要同时检查两种主题，页面底部过度滚动和滚动条颜色也要匹配。
- 侧栏以主内容 `main` 为跟随边界；目录与导航不能重叠。仅内容超出可视高度时出现内部滚动，避免无效留白；头像阴影不被容器裁切。
- 菜单选中、悬浮发光和移动背景保持连贯，不闪烁。无链接社交项保持摇头提示；点击提示保持单行并适应窄屏边界。
- 右下角进度按页面实际可滚动距离计算，滚到底部才是 100%；评论按钮不能因顶部大图可见而失效。音乐面板与工具栏保持间距。
- 贴着顶部大图的主卡片不加顶部圆角，独立卡片保留圆角。保留既有阴影效果，不能为了修复裁切重新设计整套阴影。
- 关于与友链保留主题 Markdown 标题、锚点、图标和时间等表现，通过专用布局分开主内容与评论；不影响普通文章模板。关于页侧栏使用站点概览。
- 友链数据保留 `site`、`desc`、`url`、`image`、`color`，不再要求 `owner`。未加载的头像先显示站点首字占位，图片加载成功再覆盖，悬浮时不能闪烁或与卡片背景混为一体。
- 赞赏目前关闭；复制正文不自动追加版权文本；保留主题控制台署名。搜索使用本站本地索引，不应误触发旧 Algolia 上传流程。
- 页脚保留文字量、代码行数和访问次数。中文按字、英文按单词统计，正文统计排除代码、Markdown 标记和 URL；代码行数另计。阅读时长由统一实现计算，文章页和全站统计不能各自使用不同口径。

## 评论系统与性能

前端使用 Waline，地址来自 `_config.shokaX.yml`，公开服务为 <https://waline.sycamore.top>，管理入口为其 `/ui`。按已完成的迁移记录，服务使用 Vercel + 新加坡 Neon PostgreSQL，服务端固定在 Waline 1.43.4；这些部署信息不由本博客仓库自动保证，修改前需重新核实线上配置。

- 平常保留延迟初始化，评论进入视口前两个屏幕时开始加载；主动点击评论按钮或评论锚点时立即加载并立即启动平滑滚动，不等待请求或图片完成才滚动。
- 评论模块共享同一次加载请求，模块加载失败后允许重试。图片晚到时平滑校正定位，用户手动滚动可取消；数字开头的评论 ID 不能作为不合法的 CSS 选择器使用。
- 通过 `crossorigin` 预连接提前建立评论域名连接；它不会提前查询所有文章评论，也不能消除接口、数据库或外部头像的延迟。
- 评论正文请求、表情、头像和反应统计是不同请求。性能排查记录各自耗时，区分首次连接、浏览器缓存、函数执行和数据库唤醒。不能仅看到慢就断言“冷启动”。限速模拟不等于真实国内网络测试。
- 不为提速移除评论 HTML 安全过滤，不缓存登录用户的私有响应，不通过定时刷接口维持服务活跃。
- 历史评论迁移先完整备份，再只改路径；保留 ID、回复关系、内容和时间，迁移后核对记录总数与关联。备份留在 `.local-backups/`，禁止进入公开仓库、静态页面或截图。
- 不能只凭同名判断是同一评论人，也不能擅自合并匿名身份或替换他人的头像。测试发评论、改后台配置和迁移数据库需遵循当次授权范围。
- 邮件发送账户与通知收件人是独立配置。历史约定的发件名为“Waline评论系统”，主题文案为“New comment on your Blog”；具体凭据只在服务端配置，不写进 README、日志或前端。

## 外部脚本与安全检查

`lib/vendor-assets.json` 记录固定版本的 CDN URL、SHA-384 和本地路径，副本保存在 `source/vendor/`。涵盖 Pace、jQuery、Fancybox、Justified Gallery、KaTeX copy-tex、Busuanzi，以及图片查看器 CSS。其他字体、图片、样式和 JSON API 不属于这份可执行脚本清单。

- CDN 优先：浏览器通过 Fetch 的 `integrity` 校验响应，验证成功后才执行。下载失败、校验失败或超过 6 秒，改读本地副本，并使用相同校验值。请求共享一次加载，避免重复执行。
- 正常加载不会额外下载本地副本；新增加载器有一个很小的本地请求。CDN 卡住时会等待最多 6 秒再回退，不能理解为所有网络条件下都没有性能成本。
- 生成前校验本地副本；页面出现未登记的外部脚本时停止生成。更新资源须审查来源与内容，同步更换本地文件和校验值，不在构建时自动接受远端新内容。SRI 只验证字节一致，不检测原版本自身漏洞。
- Busuanzi 的 JSONP 数据随请求变化，不能固定哈希。外层脚本仍校验并提供固定备用内容，JSONP 仅在 `sandbox="allow-scripts"` 的无同源权限 iframe 内执行；父页面核对消息来源，仅接收非负安全整数并以文本显示。沙箱通过 CSP 限制网络来源。数据服务故障不能由静态副本补救，不显示编造的访问量。
- 评论 HTML 过滤继续保留。前端过滤不能替代 Waline 服务端的认证、权限、版本和限流检查。
- 当前未启用 Waline 的 reCAPTCHA 或 Turnstile。其动态验证码脚本不在固定副本范围内；以后启用时须另行评估，不能将这套机制视为已覆盖验证码服务。
- 主题入口等待固定脚本就绪后再初始化，并兼容 `DOMContentLoaded` 已触发的情况。调整加载顺序时必须检查加载动画能否退出，不能只检查资源请求成功。

执行 `node tests/vendor-security.test.js`，并用独立浏览器模拟 CDN 请求失败、内容被篡改和超时，检查本地回退、单次执行与沙箱隔离；再检查页面交互。依赖审计使用 `pnpm audit`，按实际调用链区分线上、构建和未启用功能，不能将告警条数直接等同于可利用漏洞数。

### 依赖审计维护

`pnpm-workspace.yaml` 中的 `overrides` 固定已核查的传递依赖修复版本；它与 `package.json`、`pnpm-lock.yaml` 一起维护。升级主题或渲染器时检查上游是否已修复，再决定是否移除覆盖。不要使用审计忽略规则代替修复。

Markdown-it 14 的内部模块改用 `.mjs` 后，旧目录和中英文间距插件的导入路径由安装补丁修正。依赖升级后须进行干净构建，并运行 `node tests/markdown-compatibility.test.js`；增量生成可能沿用文章缓存，无法证明渲染器可重新加载所有插件。

2026-10-18 的更新将审计结果从 79 条降到 6 条（严重 0、高危 4、中危 1、低危 1）。这是当日依赖数据库的结果，不是永久安全保证。剩余项：

| 依赖 | 未解决原因与使用边界 |
| --- | --- |
| `extract-zip`（2 条高危） | 尚无修复版本，由 Markdown 渲染器的 Puppeteer 浏览器安装链带入。不要用它解压不可信归档；此次安装跳过依赖脚本，未触发浏览器下载。 |
| `basic-ftp`（高危） | 修复需升至 6.2.1 以上，上游 `get-uri` 仍依赖 5.x。仅由 Puppeteer 的代理下载链带入；未强制跨主版本覆盖。 |
| `braces`（高危） | 尚无修复版本，构建和文件监听依赖会使用。避免将不可信输入作为 glob 模式。 |
| `sprintf-js`（中危） | 尚无修复版本，Hexo 国际化依赖会使用。不要将外部输入作为格式字符串。 |
| `katex`（低危） | 修复需升级至 0.18.2 以上，现有渲染器仍声明 0.16.x，主题样式也需同步验证。公告的触发条件包含已有原型污染；仍保留告警，不能据此声称安全。 |

Waline 后台与博客依赖分别维护。`IPQPS` 未显式设置时，官方默认值为 60 秒；它控制同一 IP 的评论发布间隔，不是通用 API 限流。避免给跨域评论 API 直接套全站 JavaScript Challenge：返回的验证页可能破坏客户端 JSON 请求。密钥轮换需作者完成，不能将新旧值写入仓库或聊天记录。

## 验证与发布

修改后先生成，再运行与改动相关的检查。例如：

```sh
node tests/theme-patches.test.js
node tests/category-directory.test.js
node tests/category-navigation.test.js
node tests/category-pagination.test.js
node tests/category-motion.test.js
node tests/archive-page.test.js
node tests/comment-anchors.test.js
node tests/comment-navigation.test.js
node tests/image-dimensions.test.js
node tests/post-image-optimization.test.js
node tests/cover-optimization.test.js
```

部分测试读取 `public/` 或 `db.json`，必须在生成后执行。按实际改动选择测试，不用重复运行无关检查代替视觉验证。

至少检查电脑和手机窄屏的实际页面与截图：长标题、横向溢出、分类链接和分页、深浅色、评论按钮与跨页锚点；涉及图片时另查加载前后占位、放大、关闭和多图切换。说明哪些是模拟视口，哪些经过真机验证，哪些只是抽查。

**默认仅本地修改。提交、推送、公开发布均须取得明确授权。** 获准后按功能拆分 commit，核对 `git status`、提交范围和实际发布脚本，再执行：

```sh
# 确认生成物对应获准发布的源代码后
NODE_USE_ENV_PROXY=1 node_modules/.bin/hexo generate
git push origin source
npm run deploy
```

如果工作区还存在未获准发布的改动，应从获准提交的干净快照构建，不能直接发布混入其他工作的 `public/`。完成后确认 GitHub Pages 部署结果，并检查线上实际页面；本地正常不代表线上已更新。私有备份、环境文件、API 凭据和浏览器测试产物不得随站点发布。
