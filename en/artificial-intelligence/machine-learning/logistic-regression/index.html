# Logistic regression

Logistic regression is used for classification. There are two steps: choose the form of the decision boundary, then find the coefficients that minimise the loss.

The classification problem

The sigmoid function S(x)=11+e−xS(x)=\frac{1}{1+e^{-x}}S(x)=1+e−x1​ maps a score to a value between zero and one. The curve is shown below. With a threshold of 0.5, values above the threshold are assigned class 1 and values below it class 0.

From a score to a probability

Write P(x)=11+e−g(x)P(x)=\frac{1}{1+e^{-g(x)}}P(x)=1+e−g(x)1​. The decision boundary is where g(x)=0g(x)=0g(x)=0. Taking g(x)=xg(x)=xg(x)=x gives the sigmoid curve above; the same threshold rule applies.

A typical score has the form g(x)=θ0+θ1x1+…g(x)=\theta_0+\theta_1x_1+\dotsg(x)=θ0​+θ1​x1​+…. It can involve several variables and higher-order terms.

The loss function

The loss JJJ measures how well the prediction agrees with the label. It should be large for a confident wrong prediction and small for a confident correct one.
