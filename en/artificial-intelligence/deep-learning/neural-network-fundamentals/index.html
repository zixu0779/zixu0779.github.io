# Score function

A linear scoring function maps an input to one score per class: f(x,W)=Wx+bf(x,W)=Wx+bf(x,W)=Wx+b, where xxx represents the image, WWW the weights and bbb the bias. The weights determine how input values contribute; the bias offsets the resulting scores.

For a 32×32×332\times32\times332×32×3 image and ten classes, flattening gives a 3072×13072\times13072×1 input. The weights have shape 10×307210\times307210×3072 and the bias 10×110\times110×1. The result is a 10×110\times110×1 vector of class scores. Training seeks weights that produce the desired results.

# Backpropagation

Backpropagation gives the gradients needed to optimise the weights. Gradient descent updates WWW in the opposite direction to the gradient, using a step size α\alphaα, to reduce the loss.

The chain rule carries gradients backwards through the calculations. For [(xW1)W2]W3[(xW_1)W_2]W_3[(xW1​)W2​]W3​, work backwards from the multiplication by W3W_3W3​. Think of the computation as a set of gates. In the forward pass the output of one gate becomes the input of the next. In the backward pass each gate multiplies the gradient it receives by its own local derivative.

In the diagram, the red box is one gate. Values in green above the arrows travel forwards. Values in red below the arrows are gradients travelling back through the graph.

  • Addition: for q=x+yq=x+yq=x+y, both partial derivatives are 1. Each input receives the incoming gradient unchanged.
  • Multiplication: for q=xyq=xyq=xy, the local derivative with respect to xxx is yyy, and vice versa. The gradient passed to xxx is the incoming gradient multiplied by yyy.
  • Maximum: when there’s a unique maximum, that input receives the gradient. The smaller inputs receive zero.

# Network architecture

  • Each layer transforms the preceding layer’s values.
  • The input width is the number of input features: three input units correspond to an n×3n\times3n×3 matrix for nnn examples. In the diagram each hidden layer has four units.
  • In a fully connected layer, each unit connects to every unit in the preceding layer. The diagram’s three weight matrices have shapes 3×43\times43×4, 4×44\times44×4 and 4×14\times14×1.
  • A nonlinear activation function transforms a layer’s result before it passes to the next layer.

Adding units increases the network’s capacity to fit the training data, but also costs computation and increases the risk of overfitting.

# Activation functions

Apply the activation function before passing values to the next layer.

Sigmoid

At the far left and right of the curve the derivative is close to zero. Multiplying small derivatives through the backward pass can make gradients vanish. A zero local derivative stops the gradient on that path. That is one reason sigmoid is less commonly used in hidden layers.

ReLU

ReLU is a common choice. Tanh is another activation function.

# Data preprocessing

  1. Centre each feature by subtracting its mean.
  2. Rescale the centred values by dividing by the feature’s standard deviation.

# Initialising the parameters

One random initialisation for a weight matrix is W=0.01×np.random.randn(D,H)W=0.01\times\mathrm{np.random.randn}(D,H)W=0.01×np.random.randn(D,H). The factor of 0.01 keeps the initial spread of the weights small.

# Handling overfitting

Two approaches are to add a regularisation term λR(W)\lambda R(W)λR(W) to the loss, and to use dropout (the “Seven Injuries Fist” of the training toolkit).

With dropout, training temporarily switches off randomly chosen units in the layers where dropout is applied. The selection changes between training steps.
